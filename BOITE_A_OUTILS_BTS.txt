BOITE A OUTILS BTS - VERSION DETAILLEE
======================================

OBJECTIF
--------
Cette fiche sert de modele rapide pour l examen.
Le but n est pas de tout apprendre par coeur ligne par ligne, mais de :
- reconnaitre la structure d un code
- savoir quoi remplacer
- comprendre a quoi sert chaque morceau
- gagner du temps en recopiant du code generic puis en l adaptant

Conseil :
quand tu copies un exemple, remplace toujours les valeurs entre < > ou les noms evidents
par tes propres noms de table, variables, champs ou pages.


======================================================
1. STRUCTURE D UNE PAGE HTML
======================================================

Code :
<!DOCTYPE html>
<html lang="fr">
<head>
    <meta charset="UTF-8">
    <title>Mon titre</title>
</head>
<body>
    <h1>Titre principal</h1>
    <p>Contenu de la page</p>
</body>
</html>

Explication :
- `<!DOCTYPE html>` indique qu on utilise du HTML5
- `<html lang="fr">` indique la langue de la page
- `<head>` contient les informations techniques invisibles
- `<body>` contient ce qui s affiche a l ecran
- `<h1>` est le titre principal
- `<p>` est un paragraphe

Quand l utiliser :
- pour creer une page HTML complete
- comme base de depart pour n importe quelle page


======================================================
2. TITRES, PARAGRAPHES, LISTES
======================================================

Code :
<h1>Titre principal</h1>
<h2>Sous-titre</h2>
<p>Ceci est un paragraphe.</p>

<ul>
    <li>Element 1</li>
    <li>Element 2</li>
</ul>

Explication :
- `h1` a `h6` servent a organiser le contenu
- `p` sert a ecrire un texte
- `ul` = liste non ordonnee
- `li` = element de liste

Quand l utiliser :
- pour presenter une page proprement
- pour afficher des informations simples


======================================================
3. LIENS HTML
======================================================

Code :
<a href="/clients">Voir les clients</a>

Ouvrir dans un nouvel onglet :
<a href="https://site.fr" target="_blank">Ouvrir le site</a>

Explication :
- `a` signifie ancre, donc lien cliquable
- `href` contient l adresse de destination
- `target="_blank"` ouvre le lien dans un nouvel onglet

Ce qu il faut modifier :
- le texte du lien
- l URL dans `href`

Exemple concret :
- aller vers une autre page
- aller vers une page de modification
- aller vers une fiche detail


======================================================
4. BOUTONS HTML
======================================================

Code :
<button type="button">Clique ici</button>

Bouton d envoi de formulaire :
<button type="submit">Envoyer</button>

Explication :
- `type="button"` = bouton classique
- `type="submit"` = envoie un formulaire

Attention :
- dans un formulaire, si tu veux envoyer les donnees, il faut presque toujours `submit`
- si tu veux juste cliquer sans envoyer, tu peux utiliser `button`

Quand l utiliser :

- bouton "Voir details"

8. TABLEAU HTML AVEC PLUSIEURS DONNEES EN PHP
======================================================

Code :
<?php foreach ($clients as $client): ?>
    <tr>
        <td><?= $client['id'] ?></td>
        <td><?= $client['nom'] ?></td>
        <td><?= $client['email'] ?></td>
    </tr>
<?php endforeach; ?>

Explication :
- `foreach` parcourt tous les elements du tableau `$clients`
- a chaque tour, `$client` represente un element
- on affiche ensuite les valeurs dans les cellules

Ce qu il faut modifier :
- le nom du tableau (`$clients`)
- le nom d une ligne (`$client`)
- les cles (`id`, `nom`, `email`)

Quand l utiliser :
- quand tu veux generer automatiquement plusieurs lignes

9. FORMULAIRE HTML SIMPLE
======================================================

Code :

    <label for="nom">Nom</label>
    <input type="text" id="nom" name="nom" required>

    <label for="email">Email</label>

Erreur classique :

- oublier `method="post"`

======================================================
17. PHP - RECUPERER LES DONNEES D UN FORMULAIRE
======================================================

Formulaire :
<form action="" method="post">
    <input type="text" name="nom">
    <button type="submit">Valider</button>
</form>

Traitement :
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nom = $_POST["nom"];
    echo "Bonjour " . $nom;
}
?>

Explication :
- `$_POST` contient les donnees envoyees par le formulaire
- `"nom"` doit correspondre au `name="nom"` du champ
- on verifie d abord que la requete est bien en POST

Version plus sure :
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $nom = htmlspecialchars($_POST["nom"]);
    echo "Bonjour " . $nom;
}
?>

Pourquoi `htmlspecialchars` :
- pour eviter qu un utilisateur injecte du HTML ou du JavaScript

19. CONNEXION A LA BASE DE DONNEES AVEC PDO
======================================================

Code :
<?php
$host = "localhost";
$dbname = "ma_base";
$user = "root";
$pass = "";

try {
    $pdo = new PDO("mysql:host=$host;dbname=$dbname;charset=utf8", $user, $pass);
    $pdo->setAttribute(PDO::ATTR_ERRMODE, PDO::ERRMODE_EXCEPTION);
    echo "Connexion reussie";
} catch (PDOException $e) {
    echo "Erreur : " . $e->getMessage();
}
?>

Explication :
- `PDO` sert a se connecter a la base et faire des requetes SQL
- `try` teste le code
- `catch` recupere l erreur si la connexion echoue
- `charset=utf8` evite les problemes d accents

Ce qu il faut modifier :
- le nom de la base
- l utilisateur
- le mot de passe

20. SQL - SELECT
======================================================

Tout recuperer :
SELECT * FROM client;

Seulement certaines colonnes :
SELECT nom, email FROM client;

Avec une condition :
SELECT * FROM client WHERE id = 1;

Avec tri :
SELECT * FROM client ORDER BY nom ASC;

Explication :
- `SELECT` sert a lire les donnees
- `*` signifie toutes les colonnes
- `WHERE` filtre les resultats
- `ORDER BY` trie les resultats
- `ASC` = ordre croissant

Quand l utiliser :
- afficher une liste
- afficher une fiche detail
- rechercher une ligne

22. SQL - UPDATE
======================================================

Code :

SET nom = 'Durand', email = 'durand@mail.com'

- `UPDATE` modifie une ligne existante
- `SET` indique les nouvelles valeurs
- `WHERE` indique quelle ligne modifier

Tres important :

Explication :

24. SQL - REQUETES UTILES
======================================================

Chercher un mot :
SELECT * FROM client WHERE nom LIKE '%dup%';

Compter :
SELECT COUNT(*) FROM client;

Faire une somme :
SELECT SUM(prix) FROM produit;

Jointure :
SELECT client.nom, commande.date_commande
FROM client
JOIN commande ON commande.client_id = client.id;

Explication :
- `LIKE` sert a rechercher un texte partiel
- `%` signifie "n importe quels caracteres"
- `COUNT(*)` compte le nombre de lignes
- `SUM(prix)` additionne une colonne
- `JOIN` relie deux tables

25. PHP + PDO - FAIRE UN SELECT
======================================================

Code :
<?php
$sql = "SELECT * FROM client";
$stmt = $pdo->query($sql);
$clients = $stmt->fetchAll(PDO::FETCH_ASSOC);

foreach ($clients as $client) {
    echo $client["nom"] . "<br>";
}
?>

Explication :
- `query()` execute la requete
- `fetchAll()` recupere toutes les lignes
- `PDO::FETCH_ASSOC` recupere les colonnes sous forme de tableau associatif

Quand l utiliser :
- afficher plusieurs lignes dans une liste ou un tableau


======================================================
26. PHP + PDO - SELECT AVEC PARAMETRE
======================================================

Code :
<?php
$sql = "SELECT * FROM client WHERE id = :id";
$stmt = $pdo->prepare($sql);
$stmt->execute(["id" => 1]);
$client = $stmt->fetch(PDO::FETCH_ASSOC);
?>

Explication :
- `prepare()` prepare la requete
- `:id` est un parametre nomme
- `execute()` envoie la vraie valeur
- `fetch()` recupere une seule ligne

Pourquoi c est mieux :
- plus securise qu une requete ecrite directement avec la valeur
- pratique quand une valeur vient d un formulaire ou d une URL

30. CRUD - COMPRENDRE LA LOGIQUE
======================================================

CRUD signifie :
- Create = creer / ajouter
- Read = lire / afficher
- Update = modifier
- Delete = supprimer

Structure classique :
- `index.php` : liste des elements
- `create.php` : formulaire d ajout
- `store.php` : enregistrement en base
- `edit.php?id=1` : formulaire de modification
- `update.php` : envoi de la modification
- `delete.php?id=1` : suppression

Explication :
- dans beaucoup d exercices, on te demande un mini CRUD
- il faut savoir faire au moins : afficher, ajouter, modifier, supprimer

Explication :

39. LARAVEL - VALIDATION
======================================================

Code :
public function store(Request $request)
{
    $request->validate([
        'nom' => 'required|max:255',
        'email' => 'required|email'
    ]);

    // traitement
}

Explication :
- `validate()` verifie les donnees avant enregistrement
- `required` = champ obligatoire
- `max:255` = longueur maximale
- `email` = doit respecter un format email

Pourquoi c est utile :
- evite d enregistrer des donnees invalides
- montre que tu sais securiser et controler les saisies

======================================================

- oublier `name` dans un input
- oublier `method="post"`
- oublier `@csrf` en Laravel
- oublier le `;` en PHP
- oublier les accolades `{ }`
- oublier `WHERE` dans `UPDATE` ou `DELETE`
- confondre `=` et `==`
- ne pas verifier que le formulaire a ete envoye
- utiliser des noms differents entre HTML, PHP et SQL

Exemple d erreur classique :
- dans le formulaire tu mets `name="email"`
- en PHP tu ecris `$_POST["mail"]`
- ca ne marche pas car les noms ne correspondent pas


======================================================
44. MODELES A TROUS ULTRA PRATIQUES
======================================================

Lien :
<a href="<lien>"><texte></a>

Bouton :
<button type="submit"><texte bouton></button>

Formulaire :
<form action="<page_traitement>" method="post">
    <input type="text" name="<champ>">
    <button type="submit">Valider</button>
</form>

Recuperation PHP :
<?php
if ($_SERVER["REQUEST_METHOD"] === "POST") {
    $valeur = $_POST["<champ>"];
}
?>

Tableau PHP :
<?php foreach ($elements as $element): ?>
    <p><?= $element['<champ>'] ?></p>
<?php endforeach; ?>

SELECT :
SELECT * FROM <table>;

INSERT :
INSERT INTO <table> (<champ1>, <champ2>)
VALUES ('<valeur1>', '<valeur2>');

UPDATE :
UPDATE <table>
SET <champ> = '<valeur>'
WHERE id = <id>;

DELETE :
DELETE FROM <table>
WHERE id = <id>;

======================================================
46. CONSEIL FINAL POUR LE BTS
======================================================

Le jour de l examen :
- commence par faire une structure simple qui marche
- si tu bloques, reviens a un modele generique de cette fiche
- adapte les noms sans changer la logique
- privilegie un code clair et logique
- pense au chemin complet :
  formulaire -> recuperation -> traitement -> base -> affichage

Ce qu il faut surtout retenir :
- un tableau = `table`, `thead`, `tbody`, `tr`, `td`
- un formulaire = `form`, `method`, `name`, `submit`
- en PHP on recupere souvent avec `$_POST`
- en SQL on fait souvent `SELECT`, `INSERT`, `UPDATE`, `DELETE`
- en Laravel on utilise routes, controleurs, vues Blade et `@csrf`
